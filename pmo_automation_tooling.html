Exec Dashboard JQL Snippets

The "Risk Radar" (Blocked & Flagged)
issuetype = Epic AND statusCategory = "In Progress" AND (Flagged = Impediment OR priority = Highest OR labels in ("Risk", "Blocked"))
Scope Creep Alert (Added post-planning)
project = "ENG" AND created >= startOfMonth() AND sprint in openSprints()
The Dependency Train Wreck
issueLinkType = "is blocked by" AND resolution = Unresolved AND statusCategory != "Done"

Jira Automation (A4J) Rules

Build these rules in Project Settings > Automation to eliminate PMO "glue work."

Rule 1: Auto-Start Epics

When a developer starts the first story, automatically move the parent Epic out of the backlog.

  • WHEN: Issue Transitioned to "In Progress"
  • IF: Issue Type = Story
  • BRANCH: For Parent Epic
  • THEN: Transition Issue to "In Progress"

Rule 2: Dependency Resolver Alert

Notify Team A instantly when Team B finishes the API they were waiting on.

  • WHEN: Issue Transitioned to "Done"
  • BRANCH: Linked Issues (Type: "Blocks")
  • IF: Status != Done
  • THEN: Add Comment: "Your blocker {{triggerIssue.key}} is complete. You can begin work."
